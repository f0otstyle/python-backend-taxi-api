## Pet-проект: сервис заказа такси

В рамках лабораторной работы я перешел от отдельных экспериментов к **полноценному бэкенд-приложению** — сервису заказа такси. Проект объединяет всё, что я изучил: 
- асинхронность (`asyncio`)
- базы данных (PostgreSQL + SQLAlchemy 2.0)
- JWT-аутентификацию
- Docker и Docker Compose.
- **Чистую архитектуру** (Clean Architecture) с разделением на слои

### Эволюция проекта

Изначально проект был написан как **монолит** — весь код в одном файле `taxi_api.py`. По мере изучения лучших практик я провел **полный рефакторинг** в слоистую архитектуру.

**Важно:** Все операции (создание заказа, назначение водителя, списание денег) выполняются в **одной транзакции**. Если что-то пойдёт не так — произойдёт автоматический откат (`rollback`), и данные останутся в целостности.

**Логика:**
1. Пользователь создаёт заказ (`/taxi`)
2. Система автоматически назначает случайного водителя
3. Запускается симуляция поездки 1 секунда
4. После завершения поездки с карты пользователя списывается сумма

| Категория | Технология | Назначение |
|-----------|------------|------------|
| **Framework** | FastAPI | Создание REST API |
| **ORM** | SQLAlchemy 2.0 | Работа с БД (async) |
| **База данных** | PostgreSQL 15 | Хранение данных |
| **Асинхронность** | asyncpg, asyncio | Быстрые запросы к БД |
| **Аутентификация** | AuthX | JWT-токены |
| **Хеширование** | bcrypt | Безопасное хранение паролей |
| **Валидация** | Pydantic v2 | Валидация данных |
| **Контейнеризация** | Docker, Docker Compose | Упаковка и запуск |
| **Тестирование** | pytest, httpx | Автотесты |


> **Важно:** После рефакторинга пути изменились — теперь они сгруппированы по префиксам.

### Аутентификация (`/auth`)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/auth/registrate` | Регистрация нового пользователя |
| `POST` | `/auth/login` | Вход и получение JWT-токена |
| `GET`  | `/auth/users/me` | Проверка авторизации |
| `POST` | `/auth/logout` | Выход из системы |

### Водители (`/driver`)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/driver/drivers` | Добавить нового водителя |

### Платежи (`/pay`)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/pay/top-up` | Пополнить баланс карты |

### Заказы (`/taxi`)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/taxi/` | Создать заказ такси | 
| `GET`  | `/taxi/` | Получить список всех заказов |
| `GET`  | `/taxi/history` | Получить историю заказов |
| `GET`  | `/taxi/{id}` | Получить заказ по ID |
| `DELETE` | `/taxi/{id}` | Удалить заказ |


#### 3. Создайте файл `.env` в корне проекта

Создайте файл `.env` (именно файл, не папку) и добавьте в него следующие переменные:

```env
POSTGRES_USER=pgAdmin
POSTGRES_PASSWORD=postgres
POSTGRES_DB=taxi_db
DB_HOST=localhost
DB_PORT=5432
JWT_SECRET_KEY=your-super-secret-key-change-in-production
```

## Запуск проекта

cp .env.example .env
